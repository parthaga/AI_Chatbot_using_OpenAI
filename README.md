# AI_Chatbot_using_OpenAI
Step1 = Install necessary libraries like streanlit using the command pip install.

Step2 = Create a file in the OpenAI_Chatbot folder named .env (this is an environmental file which has your OpenAI key in it)
with command " OPENAI_API_KEY=Your API Key from OpenAI ".

Step3 = Then copy the command from the Command_To_Run_API.text and paste it in terminal to run your AI Chatbot.
